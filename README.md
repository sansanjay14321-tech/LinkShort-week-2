# LinkShort-week-2
LinkShort – URL Shortener

Project Description

LinkShort is a URL Shortener application that converts long URLs into short and easy-to-share links.

Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js

Features

- Shorten long URLs
- Custom URL aliases
- Duplicate alias validation
- Invalid URL validation
- URL history
- Copy short links
- Full CRUD API operations

API Endpoints

Method| Endpoint| Purpose
POST| /api/links| Create link
GET| /api/links| Get all links
GET| /api/links/:code| Get one link
PUT| /api/links/:code| Update link
DELETE| /api/links/:code| Delete link

How to Run

1. Install Node.js.
2. Install dependencies:

"npm install"

3. Start the server:

"node server.js"

4. Open http://localhost:3000
